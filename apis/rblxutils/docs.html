Configuration

Endpoints used for remote configuraton of rblxutils.

/v1/package-map

Returns a JSON map for the directories to extract roblox packages to.

/v1/updates/json

Returns a JSON document describing updates, what's currently going on in the community, new updates and holidays.

/v1/updates/image

Returns a banner image for v1/updates/json. The banner image is exactly 368 by 122 pixel PNG.

Misc

Miscellaneous endpoints.

/join/

Returns a page that can be used to join games from a link.
